Connect your database

nilxcy stores your log in Supabase. Open index.html and fill in SUPABASE_URL and SUPABASE_ANON_KEY near the top of the script, then reload.

  1. Create a free project at supabase.com
  2. Run the SQL from SETUP.md in the SQL editor
  3. Copy your Project URL + anon key from Settings → API
  4. Paste them into the config constants in this file
